Power Supply
============



Clocks
======

`E` is the primary system clock. The data bus is read on its falling edge.
`Q` is a quadrature clock which leads `E` by 90 degrees.

+------+--------------+----------------------+------------------------+
|      | Crystal      | Fast (Coco 3 only)   | Slow                   |
+------+--------------+----------------------+------------------------+
| NTSC | 28.63636 MHz | 1.78977 MHz (559 ns) | 0.89489 MHz (1,117 ns) |
+------+--------------+----------------------+------------------------+
| PAL  | 28.4750 MHz  | 1.77969 MHz (562 ns) | 0.88984 MHz (1,124 ns) |
+------+--------------+----------------------+------------------------+


`RESET*`
========

`RESET*` is the main system reset line. It will be asserted on system
power up or when the reset button is pressed and will remain low for
approximately 100 ms.

It's generated by a simple RC delay circuit, so the rising edge is very
slow and it's extremely sensitive to external loading. It should only
be connected to high impedance Schmitt trigger inputs. The cartridge
must not place pull-up or pull-down resistors on this line.

Since `RESET*` is not buffered, a cartridge can use an open-collector
output to pull it low and reset the system. The Multi-Pak Interface
_does_ buffer `RESET*`, so this only works when the cartridge is
plugged directly into the side of the computer.


Microprocessor Bus
==================


On the CoCo 1 and 2, these lines are connected directly to the CPU.



`CTS*` Select
=============

`CTS*` is the primary select line for the cartridge.
It's typically used for a ROM. 8k x 8 is safe on all targets, and
earlier CoCos support 16k x 8 with 256 bytes carved out at the top
for the IOs and CPU vectors. It's asserted when:

1. the CPU reads (all targets) or writes (CoCo 1 only) in the range

   * 0xC000 - 0xFEFF on the CoCo 1 and 2
   * 0xC000 - 0xDFFF on the CoCo 3
2. the SAM / ACVC is set to address map 0 (ROMs + 32K RAM)
3. `SLENB*` is not asserted
4. the `E` clock is high


`SCS*` Select
=============

`SCS*` is a secondary / spare select line for the cartridge.
It's typically used for IO devices like floppy controllers.
It's asserted when:

1. the CPU reads or writes in the range 0xFF40 - 0xFF5F
2. `SLENB*` is not asserted


`CART*` Interrupt
=================

`CART*` is used to indicate that a cartridge with a ROM in the
`CTS*` region is connected and the system should boot from it.
It's connected to `CB1` on PIA2, which is an edge-triggered
interrupt input that asserts the MPU's `FIRQ*` interrupt.
Program Paks usually wire this directly to the `Q` clock.


`NMI*` Interrupt
================

`NMI*` is wired directly to the CPU's non-maskable interrupt input.


`HALT*` and Direct Memory Access
================================

Asserting `HALT*` forces the CPU to pause execution at the end of
the current instruction and remain paused until `HALT*` is released.

While the CPU is halted:

- The CPU's internal state will be preserved indefinitely.
- The CPU's bus IOs go to a high impedance state,
  potentially allowing another device to take control of the bus.
- The SAM will continue to refresh DRAM.
- The VDG will continue to output to the display.


`SLENB*` and Address Decoding
=============================

All three CoCos use a 74-138 decoder to generate the select lines for
most of their peripherals. Unlike other microprocessor systems, the
decoder's inputs are driven by the S0..S2 device select outputs from
the SAM (MC8803) rather than the processor address lines.


Sound
=====

The `SND` line is connected to one of the inputs of the audio
multiplexer in the DAC chip. It allows cartridges to output sound
which will be mixed with other sources and sent to the TV.
The sound signal should be AC coupled and must not exceed
3.9 volts peak-to-peak.
